# MentorHub TRD (기술 요구사항 명세)

## 1. 기술 스택

### 프론트엔드
| 항목 | 선택 | 이유 |
|------|------|------|
| 프레임워크 | Next.js (React 기반) | SSR/SSG로 SEO 유리, 풀스택 가능 |
| 언어 | TypeScript | 타입 안전성, 개발 생산성 |
| 스타일링 | Tailwind CSS | 빠른 UI 개발, 유틸리티 퍼스트 |
| 상태관리 | React Context + Zustand | 가볍고 직관적 |

### 백엔드 + 데이터베이스
| 항목 | 선택 | 이유 |
|------|------|------|
| BaaS | Supabase | 인증, DB, 실시간 구독, 스토리지 통합 제공 |
| 데이터베이스 | PostgreSQL (Supabase 내장) | 관계형 데이터 + 위치 기반 검색(PostGIS) |
| 실시간 | Supabase Realtime | 채팅 메시지 실시간 전송 |
| 인증 | Supabase Auth | 소셜 로그인 (Google, Kakao) 지원 |
| 스토리지 | Supabase Storage | 프로필 이미지 저장 |

### 인프라/배포
| 항목 | 선택 | 이유 |
|------|------|------|
| 호스팅 | Vercel | Next.js 최적화, 무료 티어 |
| CI/CD | Vercel 자동 배포 | Git push 시 자동 배포 |
| 도메인 | Vercel 기본 도메인 (초기) | 무료 시작 |

### Decision Log
| 결정 | 대안 | 선택 이유 |
|------|------|----------|
| Next.js | React+Vite | SEO 필요 (커뮤니티 플랫폼), 풀스택 기능 |
| Supabase | FastAPI+PostgreSQL | 빠른 MVP 개발, 실시간+인증+DB 통합 |
| Vercel | AWS, Railway | Next.js 네이티브 지원, 무료 시작 |

## 2. 아키텍처

### 구조: Monolith (모놀리식)
- Next.js 풀스택으로 프론트엔드 + API Routes 통합
- Supabase를 BaaS로 활용 (별도 백엔드 서버 불필요)

### 아키텍처 다이어그램
```
┌──────────────────────────────────────────┐
│                Vercel                      │
│  ┌──────────────────────────────────────┐ │
│  │          Next.js App                  │ │
│  │  ┌─────────┐  ┌──────────────────┐  │ │
│  │  │  Pages   │  │  API Routes      │  │ │
│  │  │  (SSR)   │  │  (서버 로직)      │  │ │
│  │  └─────────┘  └──────────────────┘  │ │
│  └──────────────────────────────────────┘ │
└──────────────────────────────────────────┘
                    │
                    ▼
┌──────────────────────────────────────────┐
│              Supabase                      │
│  ┌──────┐ ┌────────┐ ┌────────┐ ┌─────┐ │
│  │ Auth │ │   DB   │ │Realtime│ │Store│ │
│  │      │ │(Postgres)│ │(채팅)  │ │(파일)│ │
│  └──────┘ └────────┘ └────────┘ └─────┘ │
└──────────────────────────────────────────┘
```

## 3. 보안 요구사항

### 인증
- Supabase Auth 기반 소셜 로그인 (Google, Kakao)
- JWT 토큰 기반 세션 관리
- 로그인 필수 기능: 채팅, 멘토링 신청, 프로필 편집

### 인가
- Row Level Security (RLS) 적용
- 본인 프로필만 수정 가능
- 채팅은 참여자만 접근 가능

### 데이터 보호
- HTTPS 필수 (Vercel 기본 제공)
- 개인정보 최소 수집 (이름, 관심사, 지역)
